TANDA

Human-signed agent payouts to rupiah

Tanda is a payout desk on Celo where an AI agent can only move money if a verified human stands behind it. The agent pays in USDT over x402, Tanda checks its Self Agent ID proof before serving it, converts the dollars to IDRX over Textile FX, and pays an Indonesian freelancer in rupiah stablecoin, with a public onchain receipt for every step.

How it works

  1. A buyer agent calls the desk with a Self Agent signed request.
  2. The desk verifies the Self Agent ID proof on Celo mainnet. No proof, no payout endpoint.
  3. On a pass, the desk answers HTTP 402 with a priced payment requirement in USDT, settled through the Celo x402 facilitator.
  4. When the job completes, the desk takes a firm Textile RFQ quote for USDT to IDRX and converts from its own wallet.
  5. The desk transfers the IDRX to the freelancer and writes ERC-8004 reputation feedback, only after a settled job.
  6. Every step lands on the public receipts page with Celoscan links.

Built for the Celo Agents Open for Business hackathon. Proven live: a 0.10 USDT payment settled onchain.
